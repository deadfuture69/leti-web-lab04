# Лабораторная 04. Интернационализация

Нужны JDK 21, Maven 3.9 и Apache Tomcat 10.1. Из корня проекта выполните `mvn clean package`.
Скопируйте `target/lab04.war` в папку `webapps` Tomcat, запустите сервер и откройте [приложение](http://localhost:8080/lab04/).
Для генерации документации Java выполните `mvn javadoc:javadoc`.
